## 공개 PR의 한계

공개 PR은 원본을 그대로 이전한 것이 아니라 승인된 코드만으로 재구성한 것입니다.
원래 Git 커밋의 작성자 정보는 유지되지만 원본 PR 작성자, 리뷰어, 승인, 댓글,
번호 및 시각을 GitHub의 기본 메타데이터로 선별 이전할 수는 없습니다.
